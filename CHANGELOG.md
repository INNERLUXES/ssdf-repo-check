# Changes

## 1.0.0

First release.

- 19 practices of NIST SP 800-218 version 1.1 in four groups, with PW.3 explained as moved.
- 29 checks: pipeline, dependencies, ownership and review, tests and analysis, secrets, releases, build and containers, design documents.
- Reports as text, Markdown, JSON and SARIF 2.1.0.
- `--require`, `--require-all` and `--fail-on-problem` to use the tool as a gate in a pipeline.
- Release packages come with a CycloneDX SBOM, SHA-256 checksums and a build provenance attestation.
